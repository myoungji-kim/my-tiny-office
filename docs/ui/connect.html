Claude Code

직원은 모두 Claude Code로 일합니다. 그래서 연결은 직원 한 명이 아니라 회사에 한 번입니다 — 첫 실행에서 확인하고, 그 뒤에는 설정에서 봅니다. 어려운 부분은 연결 자체가 아니라 우리가 대신 해줄 수 없는 것을 말하는 방식입니다.

예시는 한국어·영어 둘 다 있고, 설명은 한국어로만 적혀 있습니다. Examples come in both languages; the commentary explaining them is Korean only.

준비됨

두 줄이 모두 통과하면 회사가 일할 수 있습니다. 확인은 전부 무료입니다 — claude auth status --json은 요청을 쓰지 않습니다.

범위회사 하나에 하나입니다. 직원을 고용할 때 따로 묻지 않습니다.
확인설치 · 로그인. 둘 다 돈이 들지 않는 검사입니다.
위치첫 실행의 첫 단계, 그리고 설정. 멈추면 사무실이 먼저 알립니다.

막힌 상태

둘 다 이 앱 밖에서 고칩니다. 그래서 화면이 할 일은 시도하는 게 아니라 무엇을 어디서 하면 되는지 정확히 말하고, 다시 확인해 주는 것입니다. 명령은 복사할 수 있게 둡니다.

쓰다가 멈췄을 때

로그인이 풀리거나 Claude Code가 사라지면 사무실 맨 위에 한 줄로 알립니다. 직원도 업무도 기억도 그대로이고, 새 업무만 시작하지 못합니다.

프로젝트 폴더 신뢰

폴더는 프로젝트의 것이고, 신뢰도 폴더마다 한 번입니다. 이건 비대화형 방법이 아예 없습니다 — 폴더에서 claude를 한 번 실행하고 허용해야 합니다. 프로젝트에 폴더를 정할 때 확인하고, 신뢰되지 않은 폴더의 업무는 시작하지 않습니다.

세션이 끊겼을 때

세션은 업무마다 열립니다. 하나가 끊기면 그 직원만 멈추고, 업무 카드에는 막힘 표식이 붙습니다. 상태(업무 중)와 다른 축이라 자리를 뺏지 않게 둡니다 — 상태는 오른쪽 아래 점, 끊긴 에이전트는 왼쪽 위 빨간 표식입니다. 멀쩡할 때는 표식이 없습니다.

Do & don’t

✓ DO
끊긴 표식은 상태 점과 다른 모서리에 둡니다. 하던 일과 멈춘 이유가 둘 다 읽힙니다.
✕ DON’T
상태 점을 빨갛게 바꾸면 무슨 일을 하다 멈췄는지가 사라집니다.

규칙

  • Claude Code가 먼저입니다. 판단할 주체가 없으면 아무 일도 시작하지 않습니다.
  • 연결은 회사 단위입니다. 직원마다 로그인하거나 연결하지 않습니다.
  • 토큰 입력칸을 만들지 않습니다. 인증은 Claude Code 것입니다. 이 화면이 그 유혹이 생기는 자리입니다.
  • 고칠 수 없는 것은 어디서 고치는지를 말하고 다시 확인 버튼을 줍니다.
  • 붙여넣을 명령은 복사할 수 있게 둡니다. 받아 적게 하지 않습니다.
  • 막힌 줄이 있으면 다음으로 넘어가지 않습니다. 실패할 걸 알면서 누르게 하지 않습니다.
  • 연결이 끊겨도 직원과 업무와 기억은 그대로입니다. 런타임 실패가 회사 데이터를 지우지 않습니다.
  • 세션은 우리가 띄운 것만입니다. 폴더가 같다고 남의 세션을 가져오지 않습니다.
