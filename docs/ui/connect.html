에이전트 연결

직원 한 명을 시뮬레이션에서 실제로 일하는 상태로 올리는 화면입니다. 첫 실행 화면이 아닙니다 — 회사와 직원이 생긴 뒤에 옵니다. 어려운 부분은 연결 자체가 아니라 우리가 대신 해줄 수 없는 두 가지를 말하는 방식입니다.

예시는 한국어·영어 둘 다 있고, 설명은 한국어로만 적혀 있습니다. Examples come in both languages; the commentary explaining them is Korean only.

준비됨

세 줄이 모두 통과하면 연결할 수 있습니다. 확인은 전부 무료입니다 — claude auth status --json은 요청을 쓰지 않습니다.

런타임지금은 Claude Code 하나뿐입니다. 없는 런타임은 숨기지 않고 비활성으로 둬서 나중에 생긴다는 걸 알립니다.
작업 폴더직원마다 다릅니다. 프론트와 백엔드가 다른 레포에서 일하는 게 정상입니다.
확인설치 · 로그인 · 폴더 신뢰. 셋 다 돈이 들지 않는 검사입니다.
연결 버튼막힌 줄이 하나라도 있으면 비활성입니다. 눌러보고 실패하게 두지 않습니다.

막힌 상태

셋 다 이 앱 밖에서 고칩니다. 그래서 화면이 할 일은 시도하는 게 아니라 무엇을 어디서 하면 되는지 정확히 말하고, 다시 확인해 주는 것입니다. 명령은 복사할 수 있게 둡니다.

연결된 뒤

직원 상세에 런타임 블록이 생깁니다. 세션은 우리가 띄운 것만 보여줍니다 — claude agents는 이 컴퓨터의 모든 세션을 보여주지만, 회사 것이 아닌 세션은 남의 것입니다.

사무실에서의 구분

시뮬레이션 직원과 연결된 직원은 둘 다 일합니다. 다른 건 그 일이 실제인지입니다. 상태(업무 중·대기 중)와 다른 축이라 자리를 뺏지 않게 둡니다 — 상태는 오른쪽 아래 점, 에이전트는 왼쪽 위 표식입니다.

사무실 말풍선

Do & don’t

✓ DO
에이전트 표식은 상태 점과 다른 모서리에 둡니다. 둘 다 읽힙니다.
✕ DON’T
연결 여부를 상태 색으로 섞으면 "일하는 중"과 "진짜로 일하는 중"을 구분할 수 없습니다.

규칙

  • 이 화면은 첫 실행이 아닙니다. 회사와 직원이 먼저입니다.
  • 토큰 입력칸을 만들지 않습니다. 인증은 Claude Code 것입니다. 이 화면이 그 유혹이 생기는 자리입니다.
  • 고칠 수 없는 것은 어디서 고치는지를 말하고 다시 확인 버튼을 줍니다.
  • 붙여넣을 명령은 복사할 수 있게 둡니다. 받아 적게 하지 않습니다.
  • 막힌 줄이 있으면 연결 버튼은 비활성입니다. 실패할 걸 알면서 누르게 하지 않습니다.
  • 연결이 끊겨도 직원과 업무는 그대로입니다. 런타임 실패가 회사 데이터를 지우지 않습니다.
  • 세션 목록은 우리가 띄운 것만입니다. 폴더가 같다고 남의 세션을 가져오지 않습니다.
  • 연결은 직원 한 명 단위입니다. 회사 전체를 한 번에 켜지 않습니다.
