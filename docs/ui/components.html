버튼과 메뉴 행

크롬은 무채색으로 두고 컬러는 사무실과 데이터에만 씁니다. 그래서 주 버튼도 브랜드 컬러가 아니라 니어블랙입니다. 팝오버 안에서는 버튼 대신 메뉴 행을 씁니다.

Variants

한 화면에 primary는 하나입니다. 나머지는 secondary 이하로 내려갑니다.

primary
화면의 주 행동. 솔리드 #17171c
secondary
흰 배경 + 헤어라인. 아이콘은 오른쪽
ghost
테두리·배경 없음. 보조 행동
danger
되돌릴 수 없는 행동에만
icon
원형, 연회색. 카드 안 행동
disabled
45% 불투명. 진행 중에는 라벨이 바뀌고 폭을 유지

Sizes

세 단계뿐입니다. 높이는 42 / 36 / 30, 라운딩은 항상 완전 원형입니다.

lg = 화면 주 행동 · md = 패널/폼 · sm = 카드·행 안

Menu rows

책상이나 직원 카드를 누르면 그 자리에 팝오버가 열립니다. 팝오버 안은 카드 안이므로 니어블랙 주 버튼을 쓸 수 없습니다. 대신 메뉴 행을 쓰고, 플레이어가 하러 온 행동 하나만 볼드로 올립니다.

Do & don't

✓ DO
primary 하나 + 보조 행동. 위계가 한눈에 보입니다.
✕ DON'T
주 버튼이 여러 개면 어느 것도 주가 아닙니다.
✓ DO
카드·행 안에서는 sm. 니어블랙을 쓰지 않습니다.
✕ DON'T
모서리를 깎지 않습니다. 버튼은 항상 pill입니다.

Rules

  • 화면당 primary 하나. 그 화면의 대상에 대한 행동이어야 합니다.
  • 주 버튼은 브랜드 컬러가 아니라 니어블랙입니다. 컬러는 사무실과 데이터 몫입니다.
  • 버튼은 항상 완전 원형(pill). 8px·12px 모서리를 쓰지 않습니다.
  • 아이콘은 primary·add는 왼쪽, 드롭다운·이동은 오른쪽.
  • 카드와 행 안에서는 sm + secondary/ghost만 씁니다.
  • 팝오버 안에서는 버튼이 아니라 메뉴 행을 씁니다. 행은 pill이 아니라 9px입니다.
  • 메뉴 행은 도메인이 허용하는 전이만 보여줍니다. UI가 규칙을 다시 만들지 않습니다.
  • 불가능한 행동은 숨기지 말고 비활성 + 이유 한 줄로 남깁니다.
  • 진행 중에는 라벨을 바꾸고 폭을 유지해 레이아웃이 흔들리지 않게 합니다.
  • 포커스는 :focus-visible 2px 브랜드 아웃라인, 어디서도 제거하지 않습니다.
  • 라벨은 전부 i18n을 거칩니다. 한글에 자간·대문자 변환을 걸지 않습니다.
