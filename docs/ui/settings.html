이 컴퓨터에서 My Tiny Office가 쓰는 것들

Claude Code

직원은 모두 이걸로 일해요. 로그인은 Claude Code에서 하고, 이 앱은 확인만 해요.

폴더 신뢰는 프로젝트마다 따로예요. 프로젝트에 폴더를 정할 때 확인해요.

언어

화면의 글이 바뀌어요. 직원 이름이나 프로젝트 이름처럼 직접 쓴 글은 그대로예요.

이 회사의 데이터

직원, 기억, 프로젝트, 업무가 모두 이 파일 하나에 있어요. 회사마다 파일이 따로라 서로 섞이지 않아요.

코드 폴더와 따로 있어서 브랜치를 바꾸거나 저장소를 지워도 회사는 남아요.
내보내기는 이 회사를 파일로 저장하고, 가져오기는 파일의 회사를 하나 더 추가해요. Claude Code 로그인과 폴더 신뢰는 파일에 담기지 않아요.

이 회사 삭제

직원, 기억, 프로젝트, 업무, 연혁이 모두 지워지고 되돌릴 수 없어요. 프로젝트 폴더의 코드는 그대로예요.
