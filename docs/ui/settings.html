안전 범위

직원이 이 컴퓨터에서 하는 일과 하지 않는 일

Claude Code

직원은 모두 이걸로 일해요. 로그인은 Claude Code에서 하고, 이 앱은 확인만 해요.

직원이 할 수 있는 일

모든 직원이 같은 범위 안에서 일해요. 실행할 수 있는 명령만 프로젝트마다 따로 정해요.

안내 보기

연결된 도구

Claude 계정에 연결해 둔 커넥터예요. 확인하면 이 컴퓨터의 계정에 맞는 이름으로 써요. 직원이 쓰는 건 프로젝트에서 켠 Atlassian뿐이에요.

스킬과 플러그인

이 컴퓨터의 Claude Code에 설치해 둔 것 중 직원에게 줄 것을 골라요. 고른 것만 업무에 들고 가요.

훅과 MCP 서버는 켜지지 않고, 직원이 할 수 있는 일도 그대로예요. 고르면 Claude Code에 기본으로 들어 있는 스킬도 같이 쓸 수 있게 돼요. Jira · Confluence를 쓰는 프로젝트에는 스킬만 들고 가요.

업무 시작

켜 두면 비는 직원이 대기열의 업무를 알아서 가져가요. 멈추면 새 업무는 대기열에 쌓이기만 하고, 하던 일은 마저 해요.

화면 폭

모든 화면에 같은 폭이 적용돼요. 업무 상세에서도 바로 바꿀 수 있어요. 이 브라우저에만 기억돼요.

언어

화면의 글이 바뀌어요. 직원 이름이나 프로젝트 이름처럼 직접 쓴 글은 그대로예요.

이 회사의 데이터

직원, 기억, 프로젝트, 업무가 모두 이 파일 하나에 있어요. 회사마다 파일이 따로라 서로 섞이지 않아요.

코드 폴더와 따로 있어서 브랜치를 바꾸거나 저장소를 지워도 회사는 남아요.
내보내기는 이 회사를 파일로 저장하고, 가져오기는 파일의 회사를 하나 더 추가해요. Claude Code 로그인과 프로젝트 폴더는 파일에 담기지 않아요.

이 회사 삭제

직원, 기억, 프로젝트, 업무, 연혁이 모두 지워지고 되돌릴 수 없어요. 프로젝트 폴더의 코드는 그대로예요.
