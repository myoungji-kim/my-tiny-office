05

Office tiles

Every tile is a 16×16 string over a shared palette, drawn at an integer 2× scale. Room layouts are data, so a new department is a new layout — not a new drawing. A purchased tileset replaces the tile table without touching the layouts.

08

Do and don't

✓ Do
header + sidebar + workspace + inspector + strip
a pixel tilemap at an integer scale, the map as the hero
warm paper canvas, white cards, a 1.5px ink outline on containers
loud names and numbers, quiet roles and metadata
gradient fills so a bar reads as a value, not a line
one character per real employee, the same everywhere
✕ Don't
an illustration filling the viewport with chrome squeezed around it
coloured rectangles pretending to be pixel art
cold grey chrome with hairline borders — that is a SaaS console
one flat mid-tone across the whole screen
yellow as a status colour; it collides with working orange
a pixel font for the interface, or tracking on Hangul
